# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Stack

Pure static site — plain HTML, CSS, and vanilla JavaScript. No build step, no dependencies.

## Run locally

Open `index.html` in a browser. No server needed.

## Architecture

Three files, no external dependencies:

- `index.html` — calculator layout and button structure
- `script.js` — all calculator logic (input handling, arithmetic, keyboard support, decimal validation)
- `styles.css` — responsive layout and visual design
